## 产品边界（摘要）

OpenWork 的核心职责：**身份、组织、协作、审批、考勤与开放集成。**

不作为内置核心业务：ERP、CRM、MES、WMS、TMS、财务核算、完整 HR 薪酬、复杂项目管理、大型文档协作套件。

这些能力通过企业应用、开放 API、连接器与 WebView 扩展。

---

## 产品原则

1. 轻量化——专注企业协作基础能力，不引入非必要业务模块
2. 开源开放——Apache-2.0，允许商业使用与二次开发
3. API First——核心能力通过标准化 API 提供
4. 多租户——SaaS 实例服务多个企业，数据严格隔离
5. 私有化——可独立部署，不依赖官方服务
6. 跨平台——Android / iOS / Web / Windows / macOS / Linux
7. 模块化——业务边界清晰
8. 可扩展——开放 API、连接器、SDK、WebView
9. 安全性——认证、权限、隔离、审计为基础能力
10. 部署简便——降低中小企业的部署维护成本
