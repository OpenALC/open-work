# 事故复盘

回滚、线上故障、安全事件必须产出一份复盘，流程见 [../release.md](../release.md) §七。

---

## 命名

```text
YYYY-MM-DD-<slug>.md
例：2026-11-07-migration-lock-timeout.md
```

---

## 原则

1. **对事不对人。** 复盘目标是改进系统与流程，不是追责。
2. **时间线必须精确。** 到分钟，标注信息来源（日志、告警、人工观察）。
3. **区分直接原因与系统性原因。** 只修直接原因会再次发生。
4. **行动项必须有负责人与期限。** 没有行动项的复盘等于没做。
