# 已知问题

本文件记录**执行期发现但不在当前长任务范围内处理**的问题。它是流程的一部分：让 LLM 在执行长任务时可以把问题留痕后继续前进，而不必停下来等待决策。

---

## 使用规则

1. 长任务执行中遇到以下情况，登记后**继续执行**：
   - 同一 CI 失败连续修复 3 次无效
   - 发现与当前 LT 无关的既有缺陷
   - 需要跨模块协调才能解决的问题
   - ADR 未覆盖、已按最保守方案实现但存在疑问
2. 登记必须包含：**现象、复现方式、影响、为何现在不修、建议处理方式**
3. 不要作为"我有疑问所以没做"的垃圾桶——功能没做完不算已知问题
4. 里程碑审查时逐条评估：修复 / 接受 / 转成新的 LT
5. 关闭时保留记录并标注关闭方式与版本，不直接删除

## 字段说明

| 字段 | 说明 |
|---|---|
| ID | `KI-<编号>`，递增不复用 |
| 严重度 | `P0` 阻塞使用 / `P1` 影响主要功能 / `P2` 有替代方案 / `P3` 轻微 |
| 状态 | `OPEN` / `ACCEPTED`（决定不修） / `CLOSED`（已修） |
| 发现于 | 里程碑 / 长任务 ID |
| 关联 | Issue / PR |
