# 架构决策记录（ADR）

本目录记录 OpenWork 的架构决策。每条 ADR 说明**在什么背景下、做过什么选择、为什么、代价是什么**，供后来者（包括 AI agent）在不重新推导的前提下做出与既有设计一致的决定。

---

## 规则

1. **一条 ADR 一个决策。** 只记"为什么这么选"，不写功能说明。
2. **不删除、不改写结论。** 决策被推翻时，新增一条 ADR 并在两条上加 `Supersedes` / `Superseded by` 链接。
3. **状态明确：** `Accepted`（已采纳）、`Superseded by NNNN`（已被取代）。
4. **必须写代价。** 没有只有好处的决策。写明放弃了什么、接受了什么限制。
5. **按需写，不为凑数写。** 没有争议的选择不需要 ADR。
